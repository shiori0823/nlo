## 配色の方針（視認性優先）

50代・老眼の方が離れた位置から読めることを最優先にしている。

- 白地（`#FFFFFF` / `#F2F2EF`）に黒文字（`#111418`）。黒地は使わない
- 補助文字も `#3C4248` までに留め、薄いグレーは使わない
- 強調は赤 `#C8102E`、数字は濃い青 `#0B5FA5`。いずれも白地で6:1以上の明度差
- 赤ベタに白抜き文字は使わない。強調箇所は白地＋赤枠＋黒文字で出す
- 最小文字サイズ 30px、本文は34px以上。枠線は3px以上

写真の元データは `assets/midote/`。
