# instagram-png — トライアルキャンペーン カルーセル

Instagram フィード投稿用。1080×1350px（4:5）、8枚。
番号順にそのままアップロードする。

| ファイル | 内容 |
| --- | --- |
| `01.png` | フック「自分では、絶対に気づけなかった。」 |
| `02.png` | 悩み（身体の左右差） |
| `03.png` | やったこと（1年間、パーソナル＋フリーウェイト） |
| `04.png` | 変化（※個人の感想です を明記） |
| `05.png` | 本人の言葉「自分でやっていたら…」 |
| `06.png` | パーソナルだと何が変わるか（3点） |
| `07.png` | 本人の言葉「何歳になっても関係ない。」 |
| `08.png` | トライアルの条件とCTA |

## 決めごと

- 配色・書体はサイネージ／ポスターと共通（白地・黒文字、赤は枠線と見出しのみ）
- 体験談は**ご本人の感想として**書き、「治る」「矯正」などの断定表現は使わない
- 変化に触れる04には「※個人の感想です。効果には個人差があります。」を必ず入れる
- 01と08以外は写真を使わない。体験談の本人と、写真に写っている方を混同させないため

元データは `print/instagram-trial.html`。書体は埋め込み済み。
作り直すときは `scratchpad/ig.mjs` と同じ手順で 1080×1350 を書き出す。

## ストーリーズ版

1080×1920 が必要な場合は、同じ内容で作り直せる。
