## 差し替え方法

同じファイル名で置き換えれば、そのまま反映されます。表示枠は
`object-fit: cover` なので、比率が違う画像でも枠に合わせて自動で
トリミングされます。

トリミング位置を変えたい場合は `index.html` の該当箇所にある
`--pos`（`object-position`）の値を調整してください。
例：`--pos:50% 22%` は「横は中央、縦は上から22%」を基準にします。

写真ファイルが無い場合、講師写真の枠には差し込み位置のガイドが
表示されます。
