# assets

## 講師写真の差し替え方法

このフォルダに `kosugi.jpg` というファイル名で講師写真を置くと、
LP の「講師｜小杉先生」セクションに自動で表示されます。

- ファイル名：`kosugi.jpg`（変更する場合は `index.html` の `src` も合わせて変更）
- 推奨サイズ：600×800px 以上
- 縦横比：3：4（縦長）。別の比率の画像でも中央基準で自動トリミングされます
- 形式：JPEG（`.png` や `.webp` を使う場合は `index.html` の `src` を変更）

写真が未設置のあいだは、差し込み位置を示すガイドが表示されます。
