## 配色

ノーリミッツ岡山のブランドカラー。白地・黒文字、差し色はオレンジのみ。

- 白 `#FFFFFF` / 淡い地 `#F7F4F0` / オレンジの淡色 `#FDEEE2`
- 文字 `#111418`（黒）、補助 `#4A4F55`
- オレンジ `#EA6A1E`（面・ボタン）、`#C2510D`（文字）
  - 小さい文字のオレンジは濃いほうを使い、白地で4.5:1以上を確保している
  - ボタンはオレンジ地に黒文字（6.6:1）

ライトテーマ固定。ブランド指定が白地・黒文字のため、ダークモードは入れていない。
